# Эмулятор командной оболочки UNIX (ИКБО-63-25, Вариант №24)

## 1. Общее описание

Данный проект представляет собой эмулятор командной оболочки UNIX, написанный на языке Python. Эмулятор работает в интерактивном режиме (REPL) или выполняет стартовый скрипт. 

Основная особенность проекта — работа с виртуальной файловой системой (VFS), которая загружается из CSV-файла в оперативную память. Все операции с файлами и каталогами производятся исключительно в памяти, исходный CSV-файл не модифицируется.

Проект состоит из 5 этапов:
1. **REPL:** Базовый интерфейс командной строки, парсер команд, обработка ошибок.
2. **Конфигурация:** Поддержка аргументов командной строки и выполнение стартовых скриптов.
3. **VFS:** Виртуальная файловая система на основе CSV с поддержкой вложенности и Base64.
4. **Основные команды:** Реализация `ls`, `cd`, `cat`, `echo`, `find`, `tac`, `who`.
5. **Дополнительные команды:** Реализация `mkdir` (изменение состояния VFS в памяти).

## 2. Описание всех функций и настроек

### Параметры командной строки (Настройки)
Эмулятор поддерживает следующие аргументы при запуске:
*   `--vfs <путь>` (обязательный): Путь к каталогу, в котором находится файл `filesystem.csv`, описывающий виртуальную файловую систему.
*   `--script <путь>` (опциональный): Путь к стартовому скрипту (файлу `.sh` или `.txt`), команды из которого будут выполнены последовательно при запуске.

### Структура VFS (CSV)
Файл `filesystem.csv` должен иметь следующие колонки:
*   `name`: Имя файла или каталога.
*   `parent`: Путь к родительскому каталогу (например, `/` или `/folder1`).
*   `type`: Тип узла (`file` или `dir`).
*   `content`: Содержимое файла (обычный текст или строка в кодировке Base64 для бинарных данных).

### Поддерживаемые команды
| Команда | Описание |
| :--- | :--- |
| `ls [путь]` | Вывод списка файлов и каталогов. |
| `cd [путь]` | Смена текущего каталога. |
| `cat <файл>` | Вывод содержимого файла. |
| `echo <текст>` | Вывод текста на экран. |
| `mkdir <каталог>` | Создание нового каталога (только в памяти). |
| `find <путь> -name <шаблон>` | Поиск файлов по шаблону. |
| `tac <файл>` | Вывод содержимого файла в обратном порядке. |
| `who` | Вывод информации о текущем пользователе. |
| `exit` | Выход из эмулятора. |

### Основные классы и функции
*   `src/main.py`: Точка входа в приложение, парсинг аргументов.
*   `src/vfs.py`: Класс `VFS`. Отвечает за загрузку CSV, разрешение путей (`resolve_path`), создание каталогов (`create_dir`), чтение файлов (`read_file`) и поиск (`find`).
*   `src/shell.py`: Класс `Shell`. Содержит логику обработки команд, парсинг ввода с помощью `shlex` и методы `cmd_*` для каждой команды.
